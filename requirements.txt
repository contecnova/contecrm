# Dependencias de RUNTIME de todos los servicios.
#
# Versiones fijadas con `==` en lo que toca el camino crítico (web, datos, bus)
# y con rango en lo que solo aporta comodidad. El criterio: si una subida menor
# puede cambiar el comportamiento en producción, se fija.
#
# Lo específico de un servicio va en `services/<nombre>/requirements.txt`, que
# se instala ADEMÁS de este. Así el gateway no arrastra el motor de plantillas
# del servicio de documentos ni al revés.

# ── Transportes de sistemas heredados (CRM-00.03.04.03) ───────────────────
# SFTP y AMQP no se pueden hacer con la librería estándar, y un CRM que se
# integra con ERPs de verdad los necesita: media industria sigue intercambiando
# ficheros por SFTP y colas por AMQP. SOAP, ficheros planos y EDI sí van con lo
# que ya hay —son HTTP con XML y texto con separadores— y no añaden dependencia.
paramiko==5.0.0
aio-pika==10.0.1

# Passkeys (WebAuthn, CRM-00.05.01.23). Va aquí y no en un extra opcional
# —como SAML— porque es Python puro sobre `cryptography`, que ya está: no
# obliga a compilar nada ni a instalar librerías del sistema. Y una passkey es
# la única credencial de esta lista que **no se puede robar por phishing**,
# así que ponerla detrás de un paso de instalación extra sería dejar la mejor
# fuera por comodidad.
webauthn==2.5.0
