# librería. Sin ella, `crmcore.rpc.servidor.disponible()` devuelve False y
# levantar el puerto falla diciendo exactamente esto.
#
#     pip install -r requirements-grpc.txt
#
# Y después, en el `.env`:  GRPC_ACTIVO=true
